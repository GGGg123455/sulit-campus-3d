# 苏理工三维校园 · V15

V15 修正：撤回海纳楼北侧等 4 处停车用途误判；保留略高沿楼人行道。电信院连廊改等宽直线，C 楼补沿楼硬地与绿岛。球场外围绕行并对全部 24 块篮球/网球/排球场执行铺装避让；去掉体育馆前场重复步道。行政楼顶部窗面按楼层拆分，与普通窗统一尺寸；建筑、水体和地面材质更新。以上是影像参考和用户确认的展示修正，米制尺寸仍未实测。

江苏科技大学苏州理工学院校园三维展示，包含建筑、道路、人行道、内院铺地、水系、小桥及卫星叠加核对。

本轮：体育馆外楼梯改至南北两端；沥青路两侧补略高人行道，步行与车行交接处设顺坡；28条浅色窄通道按步行铺地复核，入口采用平口和连续路口边界。补查15处内院及沿楼硬地，保留可见绿岛；一食堂补出卫星可见的小型开敞内院。

保留原40个建筑、附属及范围对象，另按用户确认区域补3排教师公寓体量，共43个轮廓对象。宿舍6层、教学及学院5层、行政8层；海纳楼二层连接、西侧上下两层连接、A—D弧形/D—C直线等宽首层廊、B/C连体楼及行政楼统一窗格保留。四门伸缩门均关闭，无抬杆；西门题字为“笃学明德”“经世致用”。食堂仍用改造前口径。
