# 苏理工三维校园 · V12

江苏科技大学苏州理工学院校园三维展示，包含建筑、道路、水系、小桥和卫星影像叠加核对。

按用户标图更新两条等宽、首层有顶开敞连廊：A—D 为弧形，D—C 为直线。A—B 无连廊，B/C 连体楼保留。海纳楼西侧首层连接朝西的一面封闭，中央保留较大的通透门洞；三层连接保留。

行政楼普通窗格采用统一尺寸与窗距，玻璃颜色统一，圆弧端横线对齐参考楼层。

全部 40 个建筑、附属及范围对象保留。建筑高度、未见立面及连廊精确尺寸仍为调研参考，不属于实测验收模型。食堂沿用改造前口径。
