苏理工三维校园 V13：GitHub Pages 发布包

本包根目录的 index.html 是网站入口。包含完整模型、材质、JavaScript 库、布局与兼容渲染资源；所有运行资源均为相对路径，无需额外 CDN，可放在 GitHub Pages 的仓库子目录下。

最简单的网页上传方式：
1. 在 GitHub 创建一个公开仓库；也可以使用已授权的校园展示仓库。
2. 将本 ZIP 解压，把里面的全部文件和子文件夹上传到仓库根目录。不要只上传 ZIP，也不要多套一层目录。
3. 仓库 Settings → Pages → Build and deployment：Source 选择 Deploy from a branch；Branch 选择 main / (root)，然后 Save。若默认分支为 master，就选 master。
4. 等待 GitHub Pages 构建成功，使用该页面显示的正式访问地址。
5. 保留 .nojekyll 文件，之后更新网站时替换相同文件。

维护完整源码时：源码仓库已附 .github/workflows/pages.yml，直接部署 dist；这一路径需在 Pages 设置中选择 GitHub Actions，不与上述根目录分支发布混用。
官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

当前只是完整上传包；只有取得 GitHub 仓库访问权限并实际部署成功后，才能提供该仓库的正式网址。GitHub Pages 在中国大陆的访问速度与可用性尚未实测，不能承诺所有网络均稳定。
